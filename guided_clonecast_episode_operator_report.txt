CloneCast Compatibility Finding
-------------------------------

CloneCast exposes supported CLI commands for research ingestion, episode creation, planning, generated scripts, chapter script text replacement, voice rendering, episode assembly, QC, release packaging, and publication.

However, during this phase I did not find a supported CloneCast CLI command that imports one complete owner-approved final script as the authoritative production script for voice generation while preserving it byte-for-byte. CloneCast has:

  - si-import --category script
  - episode-chapter-script-set-text

Those are not equivalent to a one-shot approved full-script production import interface.

Because the request explicitly forbids direct CloneCast database writes and forbids inventing CloneCast behavior, the AutoCorp operator truthfully stops at this integration point with a blocker instead of fabricating production success.
